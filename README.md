# Graph Database Benchmark

Benchmarking five graph database platforms using a common Mushroom graph dataset and standardized workloads.

## Platforms

- CognoDB Cloud
- Neo4j Aura
- Memgraph Cloud
- FalkorDB Cloud
- ArangoGraph

## Dataset

- Mushroom nodes: 30,000
- Attribute nodes: 116
- Relationships: 359,084
- Source dataset: Mushroom dataset
- Random seed: 42

## Benchmark

- Warm-up runs: 10
- Measured runs: 120
- Workloads: 7
- Deterministic start-node sampling
- Habitat parameter rotation
- Concurrency testing performed separately

## Status

Final benchmark measurements are in progress.
